Tìm hiểu về Support Vector Machine

Support Vector Machine (SVM) là thuật toán học máy có giám sát được sử dụng để phân loại dữ liệu bằng cách tìm một siêu phẳng tối ưu nhằm phân tách các lớp dữ liệu.

🎯

SVM hoạt động như thế nào?

SVM tìm một siêu phẳng phân chia các lớp dữ liệu sao cho khoảng cách từ siêu phẳng đến các điểm dữ liệu gần nhất được tối đa hóa.

📐

Support Vector

Support Vector là những điểm dữ liệu nằm gần ranh giới phân loại và có vai trò quan trọng trong việc xác định siêu phẳng.

01

Kernel Linear

Mô hình Iris sử dụng Linear Kernel để xây dựng ranh giới phân loại tuyến tính.

02

Tham số C

Giá trị tham số tối ưu được lựa chọn thông qua GridSearch là C = 0.1.

03

Cross-Validation

Mô hình được đánh giá bằng 5-Fold Cross-Validation với độ chính xác trung bình 97.50%.

04
